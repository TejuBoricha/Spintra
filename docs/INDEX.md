# Documentation Index

One-line purpose for every file in `docs/`, so you can pick only what's relevant instead of reading everything.

| File | Read when... |
|---|---|
| `AI_RULES.md` | You need the engineering constitution — decision priorities, quality gates, security rules. Read once per session. |
| `AI_CONTEXT.md` | You need the current state of the project — what's built, in progress, known issues, backend/DB status. |
| `HANDOFF.md` | You're resuming work and need to know exactly where the previous session stopped. |
| `TASKS.md` | You need the active task list, technical debt backlog, or future roadmap. |
| `ARCHITECTURE.md` | You're touching `room-client.tsx`, the activity/registry system, or need the DB ER diagram (§12). |
| `DECISIONS.md` | You're about to change something that might contradict a past architectural choice (ADRs) — check first. |
| `CHANGELOG_AI.md` | You want the full history of AI-driven sessions and exactly what each one changed. Append-only. |
| `ENGINEERING_GOVERNANCE_REVIEW.md` | You want an outside audit of this documentation system itself (strengths/weaknesses/risks). |

Not sure where to start? `TASKS.md` + `HANDOFF.md` together answer "what's happening and where did we leave off."
